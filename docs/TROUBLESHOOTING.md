# 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| GUI가 안 열림 | `python -m tkinter` 확인. 콘솔에서 `python windows/control-panel/virtual_screen_control.pyw` 실행 |
| PowerShell을 찾지 못함 | PowerShell 7 설치 후 새 터미널에서 `pwsh` 확인 |
| 켜기가 실패함 | setup의 `-CheckOnly` 재실행. 가상 화면의 확장·해상도·배치 확인 |
| 포트 충돌 | 이전에 실행한 다른 패키지나 프로그램의 16901 포트 확인. 임의 PID 종료 금지 |
| 실제 화면이 반복됨 | 브라우저를 실제 모니터로 이동. 앱만 가상 모니터로 이동 |
| 비밀번호 복사가 실패함 | 아직 첫 서버 실행 전이면 먼저 켜기. 실행 후에도 실패하면 자격증명 파일 접근 권한 확인 |
| 서버가 저절로 꺼짐 | 모니터 분리, 드라이버 재시작, 화면 배치 변경 여부 확인. 안정된 배치에서 다시 등록 |
| Voxl 업데이트 후 실행 불가 | 서버를 끄고 아래 재등록 절차로 실행 파일 해시 갱신 |
| 입력이 두 번 들어감 | 브라우저/자동화 도구의 중복 키 이벤트 여부 확인. 이 버전은 중복 키 입력 보정 기능을 포함하지 않음 |
| UAC/잠금 화면 조작 불가 | 일반 로그인 세션 캡처 범위 밖. 관리자 권한 상승이나 잠금 해제를 제공하지 않음 |

파일 탐색기로 폴더를 이동하면 바로가기 경로도 달라집니다. 이전 바로가기를 직접 제거한 뒤 새 위치에서 바로가기 설치 스크립트를 다시 실행하세요. 소유권 확인에 실패한 서버가 남아 있으면 원래 폴더의 끄기를 사용하세요.

비밀번호를 바꾸려면 먼저 소유 서버를 끄고, 로컬 `windows/credentials.json`을 삭제한 뒤 다시 켭니다. 실행 중에는 삭제하지 마세요. 비밀번호 파일·공유 파일·화면 캡처를 이슈에 첨부하지 마세요.

## 배치·실행 파일 다시 등록

setup은 기존 등록 파일을 자동으로 덮어쓰지 않습니다. 먼저 **해당 패키지의 끄기**로 서버를 종료하세요. 그 후 아래 네 파일을 저장소 밖의 로컬 백업 폴더로 이동하고 setup을 다시 실행합니다.

- `windows/config.json`
- `windows/stream-state.json` (생성되어 있다면)
- `windows/virtual-display/baseline-display.json`
- `windows/virtual-display/display-target.json`

`windows/credentials.json`을 유지하면 기존 비밀번호를 계속 사용합니다. 서버가 실행 중이거나 소유권 확인에 실패한 상태에서는 등록 파일을 이동하지 마세요. 백업에도 기기 식별 정보가 있으므로 공개 저장소에 올리지 않습니다.
